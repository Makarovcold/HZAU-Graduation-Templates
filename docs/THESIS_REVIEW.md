# 排版与兼容性说明

验证日期：2026-11-03。公开格式文档与技术资料见 [SOURCES.md](SOURCES.md)。

## 排版特性

| 项目 | 设置 |
| --- | --- |
| 默认字体 | Windows 环境使用宋体、黑体与 Times New Roman；提供 `portablefonts` 跨平台选项 |
| 页眉 | 奇数页为论文题目，偶数页为学校及届次 |
| 页脚 | 页码基线距纸底约 15 mm |
| 绿色封面 | 双语信息字段，英文值可换行；日期区采用单倍行距 |
| 白色扉页 | 包含题目、身份信息与学院，按固定间距排版 |
| 双面打印 | 目录和摘要结束时按需要补空白页，使摘要与正文的新页码序列从正面开始 |
| 目录链接 | 致谢有独立目标；附录的图表公式使用独立超链接编号 |
| 参考文献 | 统一常见类型的作者大小写、类型标识、年份位置和中英文标点，文内采用作者—年份制 |
| 孤行 | 防止段首或段尾仅一行被拆到另一页；仍须人工检查用户新增内容 |

## 验证范围

- 使用本地 TeX Live 2026、XeLaTeX、Biber 2.21 与 latexmk 4.87 完成构建。
- 默认匿名示例为 19 页，逐页检查渲染；第 2、4、6、8 个物理页为空白，第 9 页中文摘要，第 11 页正文。
- 检查封面、声明、目录、双语摘要、公式、伪代码、双语图表、文献、代码、跨页续表与致谢；检查目录的参考文献、附录及致谢目标。
- 用较长的中英文题目和换行的英文导师信息复核封面，仍保持单页。
- 另以跨平台字体与 36 条文献进行编译检查，覆盖书籍、期刊、会议及文集章节。测试资料仅在本地，不包含在公开包中。
- 未出现 Overfull、未定义引用或缺失字符。当前宏包组合会提示两条 `textcite` 宏已定义的警告，不影响示例输出。

## 使用前仍须核对

本项目为社区维护的通用模板。当前采用图表按节编号，而学校公开规范的图表示例为连续编号；学院要求不同编号方式时需调整。声明、封面字段、电子签名及最终 Word / PDF 形式以当届要求为准。

跨平台字体会改变字形与分页；GitHub Actions 会切换到该模式，真实 Overleaf 项目尚未实测。文献未覆盖的类型使用宏包回退样式，新增文献的作者、卷期、页码和链接必须逐条核对。模板不能保证任意长标题、宽表或长公式自动适配，定稿时应重新编译并逐页查看。
