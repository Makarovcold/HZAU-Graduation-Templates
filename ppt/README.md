# 中期与毕业答辩 PPT 模板

提供两套用途不同、设计一致的文件：

| 场景 | PPTX | POTX | 总页数 |
| --- | --- | --- | --- |
| 中期答辩 | `HZAU-Midterm-Template.pptx` | `HZAU-Midterm-Template.potx` | 12 |
| 毕业答辩 | `HZAU-Defense-Template.pptx` | `HZAU-Defense-Template.potx` | 18 |

两种格式的区别：

- `.pptx`：打开后直接修改，建议先另存为自己的文件。
- `.potx`：PowerPoint 模板，用于从模板新建演示文稿。

使用 16:9 宽屏，设计字体为 **Microsoft YaHei / 微软雅黑**，深绿配浅绿色与米白背景。字体未嵌入文件，使用其他系统时请安装可用字体或在编辑器中统一替换，然后检查换行。

## 修改方式

所有方括号中的文字都是占位内容。请替换封面身份字段、章节标题、研究内容、图表结论及参考文献。非实验类论文可以把“实验设计”改为“调查设计”“系统设计”或“案例选择”。

毕业答辩模板的图表为原生 PowerPoint 对象，包含嵌入数据表。请在编辑器中选中图表并使用“编辑数据”，修改数值、分类和系列名称。当前图表数字均为虚构演示数据，不能直接作为研究结果。

图像位置仅为占位框。可删除框后插入自己的图片，再保持比例调整大小。公式位置为文本占位，可使用 PowerPoint 的“插入 → 公式”替换。

建议通过复制已有示例页增加内容，保持现有排版。页码为可编辑文本，增删或移动页面后需要手动更新。第 18 页默认隐藏，不会在正常放映时显示。
